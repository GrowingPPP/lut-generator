# LUT 参数设计修订方案

## 设计约束

3D LUT 是在确定输入编码下的逐像素 RGB 映射。项目将技术转换、单张照片校正和可复用风格区分开：

1. **输入与输出**：STD/NAT/VIVD 使用各自 Photo Style 形成的照片信号，按 sRGB 编码处理；VLOG 使用 V-Log/V-Gamut 输入，输出 Rec.709 编码。前三者目前共享同一相对调色函数，不能声称完成了分别校准。
2. **单张校正**：冷暖、绿洋红与曝光针对当前样张或相近光线；V-Log 在显示映射前完成这些线性域校正。
3. **风格**：暗部/中间调/亮部、影调、全局及局部色彩属于可复用 look。风格强度只在“技术转换及单张校正”与“完整 look”之间插值；V-Log 的零强度仍保留正常显示转换。
4. **安全性**：单个影调算子在整个允许范围保持灰阶单调；正常值不将整张画面压成同一种颜色。33³ 网格必须能平滑重建输出。

## 问题、任务与验收

| 优先级 | 问题 | 实施任务 | 验收 |
| --- | --- | --- | --- |
| P0 | 白场 -1 全黑、黑场 +1 反转、对比度 -1 全灰 | 改用端点受控的单调影调映射；前后端同步 | 允许范围内灰阶单调，端点不反转，前后端 LUT 一致 |
| P0 | Photo Style 的作用范围不清楚 | 界面及文档明确输入、输出和 STD/NAT/VIVD 共享相对变换；修正 V-Log 样张提示 | 选择基准和下载时能看见适用的输入信号 |
| P1 | 后期版被误认为通用 LUT | 导出时注明输入、输出约定；说明其与机内版数值映射相同 | 文件与界面可辨识目标信号；相机头仍兼容 |
| P1 | 风格无法控制浓淡 | 加风格强度，分离技术校正与创意变换 | 0 强度保留 V-Log 显示转换及单张校正，1 强度是完整效果 |
| P1 | 仅有全局色相，缺少局部色彩控制 | 加色相范围内的色相、饱和度调整；增加中间调染色 | 目标色可调，范围外颜色基本不变，零值恒等 |
| P1 | 色温和 V-Log 映射名称不准确 | 写明冷暖是相对偏移；将高光映射命名为 V-Log 显示映射 | 不再暗示检测到拍摄色温或只调整高光 |
| P2 | 不同 Photo Style 缺少真正的设备校准 | 保留为需相机、色卡和对应样张的独立任务 | 不用未经测量的矩阵冒充设备校准 |
| P2 | 最后一次逐通道裁切可能改变高饱和颜色 | 测量真实素材与 33³ 插值误差后设计连续色域压缩 | 不以会造成网格插值突变的算法替换现有裁切 |

变更影调公式会使已有非零参数的重新导出结果发生变化。导出前应重新预览；此前下载的 `.cube` 文件不会被改写。相机内的实际渲染还需在对应机型与 Photo Style 下验证。

## 实施结果

P0 与 P1 的软件任务已完成，并加入灰阶单调性、风格强度、局部色彩、V-Log 处理顺序和前后端 `.cube` 一致性测试。对比中心已开放调整。P2 需要相机实测或新的连续色域映射方案，现阶段维持原有逐通道输出边界处理。

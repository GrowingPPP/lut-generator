# 第三批 UI 优化

日期：2026-10-13。状态：四项实施及软件／实际页面验收完成。

依据：[UI 审核](ui-ux-pro-max-audit-2026-10-13.md)第三批及用户授权。继续沿用整齐、充分留白、清楚层级的视觉方向和第二批规格。

## 1. 地址与恢复

- 使用 hash 地址：`#/`、`#/library`、`#/create?project=<UUID>&step=adjust`。不增加路由依赖，兼容现有部署；首页章节锚点继续工作。
- 页面、项目、四步导航进入浏览器历史；启动和安全回退使用 replace，用户主动导航使用 push。浏览器前进、返回不产生调色历史。
- 登录前保留目标地址，认证后才读取当前账号草稿及账号项目列表。URL 仅是查看请求，不能授权访问、注册或恢复任意项目。
- 请求项目必须存在于当前账号本机草稿或服务端归属列表；已删除、无权或不存在时保留有效草稿并给出回退提示。暂时同步失败给出显式重试，避免自动重放写入。
- 项目切换沿用当前草稿保存与忙碌约束；正在执行任务时禁止地址切换项目并恢复当前地址。旧异步结果不能覆盖新的导航请求。
- 步骤、页面只改变查看位置。原 File 不恢复；本机预览缓存和原文件重新绑定语义保持。

## 2. 作品辨识

- 作品卡片、详情明确标记「效果示意」「图形封面」「照片封面 · 本机」。合成图不能声称代表某张照片的真实效果。
- 在作品信息编辑提供「选择照片封面」、替换及移除。用户主动选图后在浏览器解码、缩小至最长边 640px、重新编码 JPEG 去除元数据；不发给后端或模型，不保存原文件。
- 封面使用独立 IndexedDB，按账号与资产 ID 隔离，每张上限 300KB、每账号上限 12MB。选择只是候选，保存信息后生效；取消不保存。失败保留重试及已有封面。
- 封面属于作品，不属于项目。删项目保留封面；删作品清理对应本机封面。清除浏览器数据或换设备后回到内置封面。后端封面枚举、参数修订、草稿备份保持兼容。
- 同一浏览器其他标签页收到封面变化后更新。迟到图片解码和保存不能改写另一个作品或账号。

## 3. 密码可见性

- 登录／注册密码字段右侧提供显示／隐藏文字按钮，44px 点击高度、可访问名称及按下状态；按钮不提交表单。
- 切换保留输入与焦点，切换登录／注册模式恢复隐藏并清空密码；加载时禁用。密码不进入 URL、本机持久化或日志。

## 4. 演示加载

- 首屏案例立即加载；下方案例进入视口附近（200px）后才解码、生成 LUT 与渲染，图片也使用延迟加载。
- 固定照片舞台比例和占位，加载／失败状态表达真实语义，比较效果未就绪时不可拖动。继续用正式引擎和原配方，不使用 CSS filter。
- 页面卸载停止采纳异步结果、释放 Canvas 和观察器；不修改调色数学。记录首次加载与滚动后实际计算次数、时间及布局测量，不将单次计时宣称为 Core Web Vitals 认证。

## 5. 验证

- 回归：地址解析、历史、外部导航、账号归属／删除／迟到恢复、封面容量与隔离／替换／删除；保留既有加载和状态回归。
- 前端测试、生产构建、加载预算、补丁空白检查。
- 实际页面：浅色／中性灰／深色 × 1440×900／390×844，补查窄屏与低高度窗口；刷新／返回／登录恢复、失效项目、作品封面取消保存移除、密码键盘操作、演示启动／失败。
- 仅用公开样张及隔离 API 桩。真实艺术效果、模型质量、相机实机和真实移动设备软键盘／触摸验收继续待办。

## 6. 实施结果

四项已按顺序实施。本次未修改后端、参数契约、LUT 数学或照片输出编码。

| 能力 | 主要实现 | 行为边界 |
|---|---|---|
| 地址与恢复 | `lib/appLocation.js`、`hooks/useAppLocation.js`、`hooks/useProjectLocation.js`；App／Studio／Generate 接线 | hash 仅含页面、UUID 与步骤；外部导航先核对归属／删除／忙碌；失效回退、失败显式重试；切换步骤不创建调色事务 |
| 恢复并发 | `hooks/useWorkspace.js`、`hooks/useCreationFlow.js` | 每次外部查看请求有独立序号，晚到的查询／草稿载入被丢弃；离开恢复中的页面会解除等待，不阻塞以后进入；视图偏好不随自动保存反复重放 |
| 作品辨识 | `lib/assetCovers.js`、`hooks/useAssetCovers.js`、`components/PhotoCoverEditor.jsx`、LibraryView | 独立本机存储、主动选择与保存、对象 URL 回收、标签页通知；移除回退内置封面；作品删除标记拒绝迟到保存及迟到移除 |
| 密码可见性 | `components/AuthView.jsx`／CSS | 显示／隐藏为独立非提交按钮，保留输入和焦点；切换登录／注册清空并隐藏；加载时禁用 |
| 演示加载 | `hooks/useNearViewport.js`、LandingView | 首屏立即生成，案例进入 200px 预加载区才启动一次；Canvas／观察器清理；加载和失败诚实展示，未就绪不允许比较 |

照片封面不自动从私人样张抓取，也不保存到账号数据库。封面经浏览器显示解码后缩小，是作品辨识插图，不参与统计、AI、LUT 或照片导出。照片封面的本机账号隔离不代表对共享操作系统账号进行加密隔离。

### 8.2 状态流程

| 流程 | 实际观察 |
|---|---|
| 地址打开／前进后退 | 项目 A 的调效果地址直接打开；调效果→保存作品→后退／前进，步骤与地址一致；作品库→后退恢复保存步骤 |
| 刷新／项目切换 | 刷新保持项目 A 与保存位置；项目 B 地址载入 B；原文件丢失时沿用既有重新绑定提示 |
| 失效／删除／网络失败 | 未知 UUID 和已删除 UUID 回到有效 B，无对应任意项目 POST；账号项目读取失败给出重试，重试后安全回退，当前草稿保留 |
| 封面选择和取消 | 选择后取消不写封面；原内置封面保持 |
| 封面保存／替换／移除 | 公开 hero 图编码为 38,436 bytes JPEG，preview 图替换为 81,485 bytes；移除后回到「效果示意」；重新挂载及完整刷新仍读到已保存封面；该封面操作期间没有照片上传请求 |
| 密码及登录目标 | 按钮实测 56×44；键盘激活显示后焦点回到密码输入，按下状态正确；切换注册清空并隐藏；登录后回到请求的 B／调效果地址 |
| 演示加载／失败 | 首屏未就绪时禁止比较，准备完成后舞台尺寸不变；键盘右键把比较位置 50 改为 50.1；模拟解码失败显示「示例效果暂不可用」，比较禁用，创作入口仍可用 |

### 8.3 演示启动实测

1440×900、首页页顶、正常解码的一次记录：初始只有 `chroma:landing:hero` 一次计算，耗时约 150.8ms；下方案例位于视口下方 y≈1279.9，尚无案例计算记录。滚动到案例后新增 `chroma:landing:case` 一次，约 106.5ms。首屏加载前后舞台均为约 676.6×507.4，尺寸保持。

浏览器自动恢复到之前滚动位置时，案例进入预加载范围后启动符合设计；测量首屏时使用页顶位置区分这个条件。计时包含动态模块与图片准备，是单次开发环境记录，不是跨设备性能承诺或 Core Web Vitals 认证。

# 报告与长内容排版修复

## 问题与原因

AI 创作报告展开“其余参数变化”后，多行标签的边框与文字相互覆盖。“风格贡献”和“风格被拦下”复用相同结构，也受影响。

浏览器使用真实报告组件与合成参数复现：标签是带上下内边距的行内 `span`，容器是普通块级元素。行内盒的上下内边距不增加行盒高度，换行后标签相互覆盖。仅将标签容器改为可换行的 flex 布局并增加间距，重叠即消失；父容器没有固定高度限制。

并行检查并在浏览器确认三个长内容边界：资产修订名称、保存时更新已有资产的名称提示、项目管理同步错误。连续英文名称或错误码应能换行，不能侵入或推出操作按钮。

## 设计

- 三组展开标签共用专用列表样式，自然换行，横纵间距均为 6px，不依赖标签 margin。
- 报告标签按内容撑开高度；单个长标签可在自身范围内换行，RGB 数值不能越出容器。信息标签使用普通文字光标。
- 继续沿用现有主题、字号和颜色。保留折叠交互、主要三项变化及报告业务含义。
- 资产修订行允许长名称断词；保存弹框的更新提示采用可收缩文字区域，复选框保留完整可点击大小。
- 项目同步错误采用可换行文字与完整重试按钮，在窄屏保持恢复操作可见。
- 修复限于有复现依据的内容容器，不改变公共预设按钮的排版或调色行为。

## 验收

1. 修复前浏览器几何检查能检出多行参数标签边框重叠；修复后各标签不相交、不越出所属容器。
2. 检查主要三项、其余八项、多项已应用风格和被拦风格、RGB 标签及长文本；展开与收起均可使用键盘。
3. 检查 280px、360px 报告栏，以及 390px 窄屏和桌面视口；浅色、深色、中性灰主题均可读。
4. 用允许范围内的 100 字符连续英文资产名称和长同步错误验证修订、更新提示及重试操作。
5. 执行相关前端测试、生产构建、加载检查及补丁空白检查。临时合成验收页在完成后删除。

## 验证记录

2026-10-12，使用本地合成内容、真实 React 组件和页面样式进行浏览器验收，没有发送照片或调用模型服务。

- 修复前两份报告共 54 个标签检出 84 处重叠或越界；只调整标签容器布局即可消除，确认原因。
- 修复后 390px / 1440px 视口 × 浅色 / 深色 / 中性灰 × 280px / 360px 报告栏，共 12 组检查均无标签相交或水平溢出。
- 多行 RGB、已应用风格、被拦风格及 150 字符连续英文标签均未越界；长照片名称、展开分析的长错误文本和视觉复核正文也未推出报告。
- 390px 下，100 字符英文资产名与长同步错误在三种主题均正常换行。修订、保存、项目弹框的滚动宽度分别与自身宽度一致；重试按钮完整保留。
- 键盘 Enter 展开/收起报告、激活重试，Space 切换更新复选框，Escape 关闭弹框，均通过。
- `npm --prefix frontend test`：247 项通过；生产构建、`check:loading` 和 `git diff --check` 通过。独立源码复核未发现交互回归。

几何回归采用临时浏览器验收页，完成后删除。仓库目前没有持久化浏览器测试套件；Node 组件测试不证明 CSS 几何布局，后续调整标签或窄栏样式时仍需执行上述实际浏览器流程。

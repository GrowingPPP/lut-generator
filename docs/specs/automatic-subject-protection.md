# 自动人物识别与肤色检查区域

## 用户流程

新样张默认自动识别。第一次执行照片优化前，系统在允许发送图片时识别人和定位可见皮肤检查区域；结果按来源摘要与输入基准保存在样张元数据，同条件后续调色复用。用户可查看估计区域、重新识别、改为有人／无人、画框和调整框的位置。旧明确人物标注保留为人工选择，旧未确认数据使用自动方式。

区域用于检查全局调色对肤色的影响，不增加局部调色能力。视觉模型提供的是估计区域，结合区域内颜色候选形成固定检查掩膜；不能宣称像素级皮肤分割。小区域按最低有效采样数量判断，不因不足全图 2% 而自动失去保护。人工精确圈定区域可选择框内全部像素，适配颜色候选未命中的皮肤。

## 契约与状态

- 每张样张保存 `subject_selection=auto|portrait|non_portrait`、`subject_detection`、可选 `subject_regions`、`subject_region_mask_mode`。区域为空数组代表明确移除，null代表继承自动区域。
- 识别报告版本为 `subject-regions-1`，状态为 resolved／uncertain／failed／disabled。报告包含人物结论、置信度、最多16个归一化矩形、来源摘要和输入基准。置信度阈值为保守执行策略，不视为校准概率。
- 每个区域为 `bounds=[x0,y0,x1,y1]`，kind为 face／hand／exposed_skin，并带置信度。区域位于规范化、方向校正后的完整显示图，服务器验证有限值、范围和非空面积。
- 编辑上下文增加 `subject_detection_mode`、`subject_analysis`、`skin_regions`、`skin_mask_mode`；不改变 LUT 参数。旧请求默认manual，确保恢复时不额外发送照片。
- 自动识别预处理完成后才冻结调色请求。报告和恢复比较包含实际影响保护的区域、选择和来源；人工改区域、切换样张或输入基准会使旧结果过期。

## 实现

1. 新增纯区域掩膜模块与结构化视觉识别模块。识别使用可配置视觉模型，返回失败或不确定时不推断全图颜色即人物。
2. 新增受认证、大小与并发限制的照片识别接口。原图只在请求内处理，数据库和草稿不保存照片或像素掩膜。
3. 自动修图在提出参数前解析人物证据；前端预识别后冻结请求，API直接调用缺少证据时也可执行识别。参考匹配、资产试套和逐样张验证统一使用区域掩膜。
4. 新增紧凑的人物保护面板及区域编辑入口，复用现有主题和组件。提供键盘数值编辑以补充画框操作。
5. “图像分析与复核”关闭时，不发送图片进行识别或复核；人工区域仍可用于本地／服务器确定性检查。结果说明未执行识别及修正入口。
6. 兼容旧上下文和持久作业指纹；验证自动和人工证据均绑定当前照片。

## 验证范围

确定性回归覆盖暖色无人景、人像与树皮背景、小人脸、人工无人覆盖自动有人、人工区域更改、空／错误／不确定响应、关闭图片发送、来源和输入不匹配、旧作业恢复及版本不污染当前样张。生产浏览器验证默认自动方式、结果展示、画框与键盘编辑、切页保持及请求失败恢复。

真实模型定位能力可用已授权照片做范围明确的功能验证；真实艺术效果矩阵和相机实机验收继续待办。

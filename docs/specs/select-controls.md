# 统一选择器

## 目标与方案

统一系统中用于选择工作区、展示模式、输入、导出及筛选的控件，消除浏览器原生菜单在不同平台及主题中的视觉差异。使用 Radix Select 作为交互基础，定制 CHROMA 的紧凑、清晰调色工具外观。

## 外观

- 触发器统一圆角、细边框、字段背景、文字间距与箭头，悬停、键盘焦点、展开和禁用状态可辨识。
- 菜单使用主题面板背景、边框与轻阴影，选中项显示勾号，键盘与鼠标高亮明确。长文字在菜单中可阅读，触发器内截断；菜单高度受视口约束，可滚动并自动避让边缘。
- 保留不同位置需要的宽度和紧凑程度。工作区选择有较宽空间，主题和照片缩放保持紧凑；窄屏无横向溢出。
- 深色、中性灰、浅色共用同一组件并使用现有语义颜色。菜单通过 Portal 显示，避免被侧栏、滚动容器和弹窗裁切。

## 语义与操作

- 保持全部现有选项、字符串值、空值、动态回显、禁用项和现有业务回调。菜单打开、关闭和浏览选项不修改照片或草稿，明确选择后才更新。
- 支持点击、触控、Enter、空格、方向键、Home/End 与按文字定位；选中后恢复到触发器。
- Escape 在菜单展开时只关闭菜单，第二次才关闭所属弹窗。菜单内操作不得触发照片缩放、平移或工作区快捷键；选项焦点留在可用范围。
- 保留真实表单必填校验及提交值；隐藏的原生表单字段不得进入 Tab 顺序、显示原生菜单或作为可见字段重复暴露。
- 继承参数保护、运行中禁用及 fieldset 禁用。每项选择器有明确可访问标签；动态选项更新不能意外写回业务状态。
- 单一共享组件接入首页、登录、生成、放大查看、照片输入／导出、保存风格、版本、相机说明与资产库。

## 验收

检查三种主题、390px 窄屏、顶部长工作区列表和放大窗口内的缩放菜单。验证键盘选项、只关闭菜单的 Escape、焦点恢复、禁用选项与字段保护；验证空值筛选、版本占位与导入信号必填、动态百分比回显。前端测试、参数契约与生产构建通过，并独立检查表单、焦点和 Portal 交互。

## 验收记录

- App 及 11 个组件共 23 处选择器完成迁移；原生 select 仅保留共享组件内部的隐藏表单字段。
- 前端 188 项测试、后端 3 项参数契约测试与生产构建通过；依赖审计未发现漏洞。
- 1788px 桌面与 390px 窄屏检查通过。12 项工作区菜单限制在 360px 高度并滚动；窄屏页面宽度为 390px，菜单留在视口内。深色、中性灰、浅色使用各自的主题颜色。
- `_1026453.JPG` 经输入确认正常显示对比；放大窗口显示当前动态 30.9% 和预设缩放项，选择 100% 正常生效。方向键浏览与取消选择不改变照片平移或调色历史，Escape 先关闭菜单、恢复触发器焦点，第二次才关闭弹窗。
- 保存资产窗口通过菜单／弹窗 Escape 分层关闭检查。主工作区已有一次可撤销调整时，选择器上的 Cmd/Ctrl+Z 不会撤销草稿。
- 受保护的输入基准正确禁用。导入信号双空时显示两项必填提示，聚焦第一项；选择 sRGB 后校验通过。资产种类可筛选可复用风格并恢复空值「全部种类」。

- 独立源码审核完成，快捷键与首个必填项聚焦问题已修正。验收使用临时工作区，结束后恢复原工作区和主题并移除验收数据。

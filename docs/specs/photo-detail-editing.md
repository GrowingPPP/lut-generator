# 放大查看中的参数调整

照片细节查看器加入当前草稿调色，让用户在相同缩放与局部位置持续查看调整。采用主照片区和可收起调色区；普通页面与放大窗口操作同一工作区。

## 布局及范围

- 桌面打开时展示照片与约 320px 调色侧栏；可收起侧栏获得完整照片空间，保持关闭按钮、查看模式及缩放入口可见。侧栏独立滚动，展开参数或曲线不压缩照片高度。
- 窄屏使用可展开的底部调色区，保留可用照片区域，不产生横向页面溢出。默认优先显示照片。
- 标准调色组复用普通页面的配置和组件：单张校正、风格强度、影调、色彩、局部色彩、分离色调、RGB；保留相同范围、步进、参数保护与复位语义。
- 自由曲线提供主、R、G、B 四个独立调整图，在调色栏内折叠展示，使用既有工作区曲线事务。可调整当前已应用的显示风格外部 LUT 强度，保护与输入转换 LUT 固定强度规则不变。输入技术基准及外部文件导入沿用普通工作区入口。
- 调色栏明确显示正在编辑当前草稿；提供撤销和重做。关闭查看器后在普通工作区看到同一参数，无额外应用或确认步骤。

## 编辑与查看状态

- 所有编辑直接通过现有工作区 begin/update/commit/reset/locks/undo/redo；一次连续拖动构成一次历史，参数保护阻止对应字段编辑，复位仅作用于未保护项。收起或关闭面板须结束未完成的编辑事务，避免丢失历史。
- 原图、当前效果与滑动或并排两图共享查看坐标。调色变化不重置缩放、拖动位置、分界或原尺寸来源，不重复请求或上传已加载的原照片。
- 渲染器在图像身份不变时复用 GL、纹理和画布，参数变化更新 LUT；异步外部 LUT 的过期请求不能覆盖较新的调整。已有成功效果在更新期间保留，禁止每次编辑切回原图导致照片几何变化。
- 未确认或不兼容的照片只显示原图，并解释如何确认；当前样张不适合判断效果时禁用调色入口。照片缓存与合成示意图保留明确分辨率和用途。
- 版本 A/B 是固定快照，查看时不可编辑它们。点击“调整当前草稿”后退出版本比较并编辑当前工作区，保留查看器及局部坐标。
- 照片缩放和平移快捷键只作用于查看区域。参数输入、分组按钮与曲线操作不被查看器拦截；撤销/重做支持按钮和适当键盘快捷键。Escape 关闭，焦点与页面滚动恢复。
- 错误以当前调色栏或照片区可见文案表达；输入、保护、存储或资源错误不能只出现在遮罩后的普通页面。

## 验收

用 `_1026453.JPG` 4000×4000 原尺寸在 1:1 平移后调整曝光、影调和自由曲线，确认效果实时变化、查看坐标保持及两图对齐。对同分辨率普通预览与放大窗口进行像素核对。验证一次拖动一次历史，撤销/重做、保护、复位和关闭后的参数同步；查看器键盘不妨碍滑杆和曲线。

检查 A/B 快照保持固定、显式切回草稿、兼容缓存和未确认照片、三种主题、大屏与窄屏。前端测试和生产构建通过，并独立检查事务、渲染与资源释放。

### 2026-10-10 验收结果

- 使用实际 `_1026453.JPG`，成功在 4000×4000 原尺寸 1:1 下平移后连续拖动曝光至 0.85 EV。两图变换均保持 `translate(-1603.25px, -1599px) scale(1)`；源图纹理重复上传次数为 0，规范化请求数量保持 2，画布身份不变。
- 连续曝光拖动产生一条历史；在聚焦滑杆时用 Cmd/Ctrl+Z 恢复 0 EV，再用 Shift+Z 恢复 0.85 EV，缩放与位置保持一致。保护曝光后不可调整，全部复位保留受保护的 0.85 EV；解除保护后组复位恢复 0 EV。
- 自由曲线四个图独立展示。主曲线控制点方向键调整不移动照片；拖动时 Escape 恢复原控制点且查看器保持打开，坐标输入 Escape 取消输入，随后 Escape 关闭查看器。关闭后普通工作区显示同一曝光参数。
- 同分辨率像素核对：普通预览与查看器 2048×2048 原图 SHA-256 均为 `91fe3be533b4e48b8e5bdf86aa8d82a39e31aa20801bed7775926f6af6580e75`，曝光及曲线调整后的效果均为 `5d30a8f9186e1a44324b66b8b106537cabc5dae8f5e9356f46128ac25c1ceb06`。
- A/B 快照模式没有可编辑参数输入；点击“调整当前草稿”后继续保留 4000×4000、100% 及 `translate(-1683.25px, -1639px) scale(1)`。点击照片后方向键平移照片，不继续改变刚才聚焦的曝光参数。
- 390×844 视口初次打开调色栏收起；展开后照片区 390×301，调色区约 390×287，各自保持可用空间，页面没有横向溢出。浅色、灰色、深色主题检查通过。
- 撤销到不同输入基准时只显示原图，并保留历史按钮；重做恢复到兼容输入后重新显示效果和参数控件，无须关闭窗口。
- 前端 178 项测试和生产构建通过；参数契约测试继续对共享参数配置、API、AI 工具及引擎核对字段和范围。独立审查发现的外部 LUT 保护、键盘焦点和不兼容输入下的历史入口均已修正并验收。

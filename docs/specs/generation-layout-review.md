# 生成页布局评估与重构方案

日期：2026-10-10。

生成页应围绕同一张照片完成形成效果、对比微调和保存导出。当前页面按功能模块逐项追加，聊天、样张管理、诊断、AI 修图、专业参数、版本和交付长期同时出现，主预览与当前操作被长页面分开。

推荐将生成页组织为调色工作台：顶部统一工作区和交付入口，中央持续显示照片，右侧一个任务工具区承载 AI 创作、手动调整和版本；诊断、样张详情及曲线工作台按需展开。现有调色能力、保护、撤销与作业恢复继续保留。

## 当前页面的主要问题

浏览器观察为 1440×900 视口、两张历史样张的草稿恢复状态，原文件尚未重新绑定。此时整个页面约 4593px 高，左侧聊天栏约 4485px 高，AI 修图输入位于约 1724px，聊天输入位于约 4501px，保存和 LUT 下载位于约 4494px。该组数字描述这次页面状态，其他素材与展开状态会改变高度。

| 优先程度 | 当前设计 | 用户影响 | 重构方向 |
|---|---|---|---|
| 高 | 左侧聊天栏随右侧全部内容伸长，输入被推到页面底部 | 进入页面看不到创作输入；滚动找工具时主照片离开视野 | 约束桌面工作台高度，主预览和任务面板各自布局，输入与操作区固定可达 |
| 高 | 两个风格文字输入分别走对话提取和照片分析，参考匹配位于第三处 | 相似描述对应不同处理方式，用户难以预测会发生什么 | 在同一工具区选择照片优化、文字微调或参考匹配，按方法表达动作 |
| 高 | 当前查看图、AI 主样张与输入状态分散 | 可能把验证图误认为 AI 来源，运行时画面切换令人困惑 | 预览上方与 AI 操作区共同显示对象，只有对象不同时突出提醒 |
| 高 | 通用状态位于全部参数和版本之后 | 保存失败、迟到响应、取消确认或未应用原因容易漏看 | 当前作业状态紧邻触发入口，阻塞问题就地提供解决动作 |
| 高 | 报告展示目标结论，但缺少冻结的当次目标；历史判定不包含目标和保护项 | 切目标后可能用当前设置理解旧报告，无法判断结果归属 | 报告常显来源、当次目标、时间和应用状态；上下文变化时标为此前结果 |
| 中 | 新会话与新工作区是同一个新建操作；会话列表和工作区切换同时出现 | 用户需理解两个近似编辑对象 | 统一工作区入口，把对话记录收进该工作区的 AI 工具 |
| 中 | 每张样张常驻元数据、输入选择、重新绑定、移除和说明 | 多样张信息压过当前照片与调整任务 | 默认缩略条与状态标记，选中后按需打开照片详情 |
| 中 | 直方图、参数形状和说明默认占较大区域 | 尚未调出效果就要读取技术数据 | 默认显示简短风险摘要；直方图和裁切位置主动展开 |
| 中 | 外部 LUT 和四块曲线排在曝光、冷暖、对比度之前 | 常用调整入口被专业工具推远 | 基础调整优先，专业工具以已启用摘要和展开入口呈现 |
| 中 | 创作目标和调整用途同时要求理解 | 用户把视觉目标与可复用风格的贡献分类混为一谈 | 创作目标靠近 AI；贡献用途保留默认规则，在高级设置与保存风格时解释 |
| 中 | 本机保存、命名版本、风格资产及下载分散 | 用户不知道是否已经完成、内容存在哪里 | 统一顶部版本、保存至我的 LUT 与导出入口，保持存储语义区别 |

## 用户任务与默认状态

主要操作链为：选择素材 → 形成效果 → 对比微调 → 保存或导出。它表达注意力顺序，不要求用户依次通过强制向导。

- 无真实照片时突出上传，保留使用合成示意图设计 LUT 的次级入口。没有真实照片时仍可手调及使用文字调整，但不能执行依赖照片分析的操作。
- 照片待确认、旧缓存或原文件缺失时，在照片区域显示一个明确解决动作；需要原文件的 AI 分析和照片导出在其入口附近解释阻塞原因。
- 照片可用时，让画面和形成效果的工具成为主内容。AI 按钮与风格输入在首屏可见。
- 微调时保持画面可见，单独滚动工具。熟练用户可保留该工作区上次使用的手动面板与专业工具展开状态。
- 满意后从固定入口比较版本、检查多张照片并保存或导出，继续允许随时调整。

## 工作台分区

### 顶部工作区栏

显示工作区名称、工作区切换、新建、草稿状态、撤销与重做。交付区集中为“版本”“保存至我的 LUT”“导出”。

本机草稿保存成功不能显示为账号 LUT 已保存。命名版本通过版本面板保存参数快照；保存至我的 LUT 继续选择完整效果或可复用风格。导出菜单分别提供机内 LUT、后期 LUT 和 JPEG/PNG 调整后照片。

### 中央照片画布

照片占据主要面积，默认原图与当前效果滑动对比。照片文件名、输入状态与展示模式紧邻画布，版本比较进入明确视图并提供返回编辑入口。

下方紧凑缩略条只标识正在查看、AI 主样张、输入及验证状态。更换查看图不隐式更换 AI 主样张。完整元数据、重新绑定、输入确认、移除和相机指南进入照片详情。

未绑定原文件的已缓存预览仍明确说明其用途。照片不可用时在画布中直接提供绑定或确认操作，避免把按钮说明藏到另一个区域。

已有兼容且规范化的缓存预览时，缺少原文件不应禁用整个工作台：预览、文字调整、手调、版本比较及 LUT 保存下载继续可用。需要原文件的照片分析、参考匹配和原分辨率照片导出分别提示绑定要求。

### 右侧任务工具区

设置“AI 创作”“手动调整”“版本”三个任务视图。默认 AI 创作，切换视图不改变参数或取消作业。照片来源、目标和当前应用状态不随工具标签丢失。

| AI 方法 | 用户目的 | 清楚表达的行为 |
|---|---|---|
| 照片优化 | 根据主样张和创作目标形成效果 | 分析并应用；显示真实阶段、保护项、取消和正式结果状态 |
| 文字微调 | 描述当前效果需要怎样改变 | 提取参数并更新当前效果；不把它表述为已测量照片。对话生成确认与参数已更新应准确区分 |
| 参考匹配 | 接近参考图的色彩和影调 | 生成匹配候选；独立预览并明确应用，说明统计匹配的近似性质 |

每种方法保留自己的输入草稿和相关设置，共用一个操作区域。默认只有当前方法的一个输入和一个主要执行动作。预设作为风格起点，历史对话收进操作记录。

AI 方法子标签同样保持异步控制器和输入状态。参考匹配的未应用候选应保留，或由用户明确放弃；切标签不应用或静默丢弃候选。

当前自动修图与文字响应的参数应用语义保留；参考图和资产载入保留候选确认。只调整布局时不能把所有入口静默改成同一种应用流程。

手动调整优先曝光、冷暖和常用影调，其后为色彩、局部色彩、分离色调、RGB、外部 LUT 与输入技术设置。已修改、受保护或已启用的高级效果在折叠标题中仍显示摘要，避免用户误认为没有生效。

### 曲线工作台与图像检查

保留主曲线及 R/G/B 四个独立编辑块。默认以曲线摘要和打开入口呈现；展开后在画布下方的专用区域显示四块，保持主照片可见。宽屏四列、中等宽度两列、窄屏单列，各通道独立选点、百分比输入、删除与复位。

收起曲线或切换工具前，明确结束或取消正在进行的拖动与未提交数值编辑，避免遗留工作区编辑事务。普通展开与收起保留参数及各通道选点。

图像检查默认给出当前照片的新增裁切风险摘要，需要时展开直方图、技术基线和裁切位置。多样张验证继续主动执行，AI 视觉复核继续属于当次结果，不合并成一个含糊的“通过”。

## AI 结果与状态呈现

结果卡先表达来源照片、当次目标和“已应用”“待应用”“未应用”或“此前结果”。再用短摘要说明主要参数变化、未完成内容和可执行动作。画面观察、详细差异、完整过程与复核意见折叠查看。

“分析已结束”“参数已改变”“草稿已保存”“账号 LUT 已保存”是不同状态。无变化结果应直接显示没有改变参数，不把尝试成功等同于风格满意或图像改善。重试、继续阶段、撤销均绑定对应结果。

本次报告的历史判定包含参数、主样张、原图摘要、冻结的目标和参数保护集合。缺少当次上下文的旧报告标为此前结果；没有应用记录时不推断“当前已应用”。技术风险结论限定为可测指标，主观视觉复核区别于统计验证。

## 响应式布局与可访问性

- 1440×900 桌面首屏可见照片、AI 输入、当前对象、主要执行与导出入口。无需滚过专业工具才能开始或结束创作。
- 中等宽度保留照片优先级，工具面板适当收窄或移到照片下方，不能压缩预览至不可用。
- 手机先显示照片及上下文，再显示任务标签和当前工具；交付入口保持易达。避免历史对话先占用半个屏幕。
- 不通过关闭标签卸载作业管理器、草稿管理或主预览生命周期；视图隐藏与业务运行分开管理。
- 控件保留标签、键盘操作、焦点状态和合理点击范围，颜色之外同时显示文字状态。阻塞原因就地解释。

本轮将评估落实为生成页重构，并保留 [可点击布局预览](../../frontend/public/designs/generation-workspace-concept.html) 作为设计记录。概念页演示布局、工具切换、曲线和交付菜单，不调用模型或生产 API，不执行真实调整、保存和导出；生成菜单中的工作台连接现有实际功能。

## 实施与验收结果

以上六项已在生成页实施。桌面采用照片区和独立滚动的任务面板；手机采用照片优先的自然布局及固定底部交付栏。自由曲线保留四通道独立编辑，宽屏紧凑图表默认完整显示，数值与通道操作通过曲线区滚动到达。

验收使用隔离的临时工作区和项目内的 `hero.jpg`、`preview.jpg`，完成后删除临时工作区、版本、会话和本机草稿，并恢复原工作区。

| 验收项 | 结果 |
|---|---|
| 1440×900 桌面 | 原两张历史样张的页面状态恢复后，文档高度为 900px；单张已确认样张时，照片优化输入与“分析并应用”按钮在首屏内，按钮底部约 732px |
| 1024×768 中等宽度 | 文档宽度与视口一致，保持照片和任务区，未出现横向溢出 |
| 390×844 手机 | 文档宽度为 390px；照片容器按 1600×1066 来源比例显示，约 366×244px；交付栏固定底部，导出菜单向上展开 |
| 输入与控制 | 样张输入确认、照片详情、方法切换时输入保留、参数调整、首次点击撤销及重做通过；修复草稿状态文字变化引起的按钮位移 |
| 四通道曲线 | 桌面四图同时完整可见；红通道数值调整仅改变红通道，一次撤销恢复；工具标签键盘切换与曲线收起通过 |
| 参考匹配 | 实际确定性请求生成 11 项调整候选；候选在工具和方法切换时保留，明确应用后才更新当前参数，整组调整可一次撤销 |
| 版本与弹窗 | 实际创建命名版本；版本入口、LUT 保存入口、工作区历史弹窗可达，Escape 关闭并恢复焦点 |
| LUT 导出 | 实际下载 33³ `.cube`，包含 35,937 行 RGB 数据 |
| 照片导出 | 实际下载 JPEG，保留 1600×1066 原分辨率及 ICC 色彩配置 |
| 回归与构建 | 前端 149 项测试通过，包括新增 8 项报告上下文测试；生产构建与 `git diff --check` 通过 |

独立审查中发现并修复参考匹配启动时未切回主样张、隐藏处理缺少可见状态、隐藏参考预览冗余渲染和报告撤销通知遗漏。浏览器验收中另修复样张详情嵌套滚动、撤销按钮位移、重复曲线标题挤压图表及手机照片容器空白。

本轮没有调用真实语言模型；自动修图的控制器恢复、取消及结果归属依赖保留的既有实现和回归测试。真实照片的艺术效果评价与相机实机导入验收继续待办。

## 曲线入口可发现性

曲线入口原位于手动参数列表底部，桌面首屏无法看到，且默认收起。照片工具栏新增“自由曲线”直接入口，可从任意工具视图进入；原入口移至手动面板顶部的固定区域，与参数列表滚动分开。入口显示展开及调整状态，展开后保持四通道独立编辑。

照片入口打开曲线时切换到手动视图并聚焦曲线区域；窄屏滚动到该区域，桌面保留照片与曲线同时可见。查看与展开允许在作业运行时使用，实际编辑仍遵守作业冻结和参数保护。展开、收起和工具切换不改变曲线数据。

验收包含：桌面手动首屏和滚动参数后入口均可见；AI/版本视图可从照片工具栏直接打开；四通道出现；窄屏进入时曲线进入视口；收起与切换不丢失数据；深色、中性灰、浅色入口均清晰可读。

2026-10-10 浏览器复现与验收：1440×900 下原入口顶部为 2016.9px，超出可见面板；调整后固定入口顶部为 229px，滚动到参数底部仍可见。从 AI 和版本页点击照片入口均切到手动并显示四通道；390px 手机打开后曲线区顶部为 1.7px，页面无横向溢出。展开、收起、切标签及切主题前后的四条曲线路径一致。收起按钮将焦点返回照片入口。前端 168 项测试通过，生产构建成功，并通过独立只读复核。

## 展开内容的空间分配

照片、样张列表、图像检查和曲线曾同时参与固定高度左栏的纵向压缩。使用 `_1026453.JPG`、1767×939 视口、输入待确认并展开图像检查与曲线时，照片实际只有 80px 高，样张列表显示 63px 而内容需要 106px，曲线内容显示 149px 而需要 334px。三个辅助区域各自滚动，使操作内容被分割和截断。

左侧改为一个连续的纵向滚动区；照片与各辅助区域不参与纵向压缩，右侧参数与顶部工作区操作仍保留固定的可见区域。桌面照片区域拥有至少 300px 的高度；待确认状态的图片自身也至少 300px，与输入确认控件分别占用自然空间，确认控件不能消耗照片的最低高度。

内容顺序为照片 → 展开的四通道曲线 → 样张列表 → 图像检查。曲线四块完整显示图形、坐标与通道操作，不限制高度或嵌套纵向滚动；图像检查的展开状态保留，展示完整内容。样张缩略条只保留横向滚动，照片详情随左侧一起滚动。

打开曲线时将编辑区标题带入左侧可见范围，避免为显示整块曲线而自动把照片滚离视野；收起时返回照片入口。窄屏继续使用页面自然滚动并定位至曲线，四通道按容器宽度展示四列、两列或一列。展开、收起、切换任务和主题不改变曲线参数；主预览及曲线组件保持挂载。

验收覆盖待确认与已确认照片、诊断及照片详情同时展开、宽屏与中等宽度两列曲线、手机单列曲线，以及坐标编辑、撤销、收起和重新展开。

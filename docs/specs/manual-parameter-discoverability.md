# 手动参数入口与新手指南修订

日期：2026-10-13。范围：普通工作台与放大调色的参数展示和帮助入口。

## 问题

默认的四项基础参数有利于新手起步，但「全部参数」作为低强调文字按钮，容易让用户误认为其他调整项已移除。新手指南放在滑杆下方，发现较晚，展开后还会拉长调色面板。

## 方案

- 将基础／全部展示改为一直可见的双选切换，使用明确的边框、选中表面和文字；基础选项标明 4 项。基础状态就地说明完整的影调、色彩和 RGB 调整仍可在「全部参数」查看。
- 完整展示按原有分组展开，保留分组状态和参数保护。切换展示只更新既有共享偏好，不改变参数、来源、照片、撤销记录或保存内容；普通与放大视图保持同步。
- 在手动工具顶部设置「新手指南」帮助入口，与标签导航并列且各自为独立控件，避免在 tab 按钮中嵌套按钮。放大调色使用同样位置和内容。
- 指南使用现有 Radix 帮助浮层：鼠标悬停可预读，点击／触摸和 Enter／Space 可固定展开；关闭、Escape 和点击外部可退出。悬停打开不抢焦点，浮层可移入阅读；窄屏正文内部滚动。
- 移除参数底部的重复指南，保留每个参数旁的「？」及现有创作建议。新帮助始终只提供阅读，不自动调整照片。
- 使用既有语义主题；触控入口和展示切换目标高度为 44px，不增加新的 UI 依赖。

## 验证

实际检查桌面与 390px 窄屏、浅色／中性灰／深色，覆盖基础与全部切换、普通与放大同步、展开分组、保护参数、指南悬停和点击、键盘关闭及焦点恢复。使用合成预览与页面级接口桩，真实模型、艺术效果矩阵和相机实机验收仍按原安排待办。

# 界面主题设计

## 使用目标

为不同光线环境和使用习惯提供可切换的界面主题，保持照片调色时的中性视觉环境。主题只改变界面配色，不改变样张、调整参数、LUT、诊断数据或导出照片。

## 主题与入口

| 选项 | 视觉设计 | 使用场景 |
| --- | --- | --- |
| 深色 | 炭黑背景、分层灰色面板、金色强调 | 暗环境，保留现有体验 |
| 中性灰 | 无色偏的中灰背景与较亮面板 | 长时间调色，降低界面与照片的明暗反差 |
| 浅色 | 浅灰背景、白色面板、深色文字、深金色强调 | 明亮环境，阅读参数与说明 |
| 跟随系统 | 随操作系统深浅外观实时切换 | 与设备外观偏好保持一致 |

首页、登录页、生成页和 LUT 库都提供同一个主题选择器。使用有标签的原生下拉控件，支持键盘与移动设备。主题名称可见，不能只用图标表示当前模式。

首次访问默认深色。用户选择立即生效，在当前浏览器保存，刷新、登录、退出和切换页面后保留。偏好独立于账号与编辑工作区，跨同源标签页同步。存储不可用时仍能在当前页面切换，不阻断产品功能。无效历史偏好回落到深色。

## 色彩约束

用语义变量表示页面、面板、输入框、文字、边框、强调、成功、警告和错误；组件不再直接绑定深色值。浅色主题使用更深的强调和状态文字，保证小字号正文与所在背景的对比度至少 4.5:1。

照片舞台、照片上的对比标签与曲线/直方图画布保持独立的中性色彩，不受主题切换影响。照片舞台统一使用中性深灰，图表保持深色，以使照片观感和 RGB 通道识别稳定。外围控制、说明、表格与弹窗随主题变化。不能对照片或整个页面使用滤镜、透明度反转等手段实现主题。

全局变量沿用 `--ink`、`--panel`、`--panel2`、`--line`、`--linestrong`、`--text`、`--muted`、`--accent`，增加 `--faint`、`--field`、`--hover`、`--accent-strong`、`--accent-soft`、`--accent-line`、`--on-accent`、`--danger` / `--danger-soft` / `--danger-line`、`--success` / `--success-soft` / `--success-line`、`--warn` / `--warn-soft` / `--warn-line`、`--info` / `--info-soft` / `--info-line`、`--overlay`、`--shadow`、`--photo-surround`、`--photo-overlay`、`--photo-text`、`--photo-muted`、`--photo-line`。参数区域的局部变量引用全局变量。

## 验收

- 三套配色覆盖首页、登录、生成、LUT 库、参数、AI 对话、参考图、导入、导出、帮助和放大对比弹窗。
- 刷新恢复选择；跟随系统响应外观变化；跨标签页同步；存储异常不报错。
- 切换主题不重建编辑器，不丢失工作区、上传样张、参数和 AI 作业。
- 同一张照片、相同参数在不同主题下，预览画布的像素完全一致。
- 桌面与窄屏入口可见、可操作，导航不发生横向溢出，表单保持可读。
- 运行主题状态测试、现有前端测试与生产构建，独立检查实际页面与配色对比度。

## 实现与验收记录

通用控件、生成工作台以及九个组件样式完成变量迁移，包括参数、AI 状态、样张、版本比较、自由曲线、图像诊断、LUT 库、照片导出、外部 LUT、参考匹配和相机指南。窄屏导航在 760px 及以下使用两行；首页在 560px 及以下将开始生成按钮独立成行。

# 通用交互与调色控件

## 产品目标

在已有 Radix Select 基础上，统一弹窗、确认、菜单、页签、参数滑块、复选框和使用说明的交互。沿用 CHROMA 的简洁工具风格与深色、中性灰、浅色主题，优先支持新手理解参数与精细调色。

## 控件方案

- Dialog 与 AlertDialog 共用弹窗基础：可访问名称、焦点圈定、关闭后恢复焦点、滚动锁定；请求执行时阻止退出。危险确认默认聚焦取消。版本与会话改名使用带标签的输入弹窗，禁止空白名称。
- 导出操作使用 DropdownMenu，分为 LUT、照片及说明，显示不可用原因；支持方向键、Esc、视口避让与选择后关闭。
- AI 创作、手动调整、版本及放大调色工具使用 Tabs。隐藏页签保留挂载，避免切换时丢失作业和编辑状态；隐藏内容不可聚焦。
- Slider 使用统一轨道、填充、焦点、禁用态和触控区域。参数数值可直接编辑，使用既有上下限与步长；合法数值提交一次，可撤销，Esc 放弃数值编辑。
- Checkbox 保持已有表单和保护语义，统一选中、焦点、禁用和主题状态。
- 参数说明使用可点击的 Popover，保留含义、增减效果、尝试建议和提醒；支持触摸与键盘，独立关闭，自动避让并支持长内容滚动。新手指南等内容折叠保留原有语义。
- 按钮、表单字段和反馈样式统一尺寸、主次、忙碌、错误及焦点；短操作提示使用 Tooltip，重要使用说明仍可主动打开。

## 业务约束

- 参数定义、默认值、LUT 运算、颜色空间、照片预览和导出链路保持既有契约。
- 参数保护、运行中禁用以及输入转换强度固定规则继续生效。
- 连续滑块拖动实时预览，一次完整手势仅产生一次历史；失去焦点、指针取消与关闭查看器后不遗留事务。
- 异步确认期间若草稿或工作区变化，应重新检查候选，旧响应不得覆盖新内容。
- 弹窗内选择器、说明浮层和菜单先处理自身的 Esc；曲线拖动和数值编辑可消费 Esc，避免误关查看器。
- 删除资产的失败重试、404 清理和已载入草稿保存能力继续保留。

## 验收

- 关键路径：样张确认、参数拖动/数值输入/保护/撤销、四通道曲线、放大查看并调色、导出菜单、版本命名与删除、资产保存及删除。
- 桌面三主题及手机窄屏：控件、说明和弹窗无横向溢出，菜单与浮层未被滚动面板裁切，正文与状态可读。
- 键盘：Tabs 方向键切换，Slider 方向键与 Home/End，菜单禁用项跳过，弹窗焦点与 Esc 分层，取消后恢复合理焦点。
- 运行现有前端测试与生产构建；新增数值边界/量化测试及针对手势历史、嵌套浮层和状态保持的浏览器验收。
- 实现后独立复核，合并重复规则和清理已失效代码。

## 实施与验证记录

已接入 Dialog、AlertDialog、DropdownMenu、Tabs、Slider、Checkbox、Popover、Tooltip，统一使用既有主题变量。工作台与放大查看共用参数控件；旧的弹窗焦点 hook、内联说明组件和导出菜单样式已移除。

浏览器验证通过：

- 使用本地 `_1026453.JPG` 确认 STD 输入，工作台与放大查看正常显示原图及调整效果。
- 连续拖动仅提交一条历史；直接输入合法数值生效，越界数值被拒绝，Esc 放弃输入；受保护参数同时禁用滑块和数值框。
- 说明浮层在查看器内独立处理 Esc，恢复说明入口焦点；选择器先关闭自身，再由后续 Esc 关闭弹窗。
- 四通道曲线保持独立显示；拖动中切换工具只提交一次，图形与参数一致；坐标输入切页正常提交。
- 曲线拖动中撤销先结束本地手势，继续移动鼠标不会重新写入已撤销内容。首次拖动可撤销；产生新分支时禁用旧分支重做，取消手势后恢复重做。
- 导出菜单打开照片弹窗后，关闭弹窗恢复到导出入口。
- 版本保存、改名、删除通过；空白名称被拒绝，危险确认默认聚焦取消，取消后恢复原入口。
- 资产保存与收藏、删除取消及实际删除通过。表单验证仅提交一份复选框及滑块值；必填复选框能聚焦可见入口，fieldset 禁用有效。
- 深色、中性灰、浅色及 390px 窄屏的说明、菜单和导出弹窗无横向溢出。

验收中修正了查看器在 Portal 内容未挂载时提前测量节点的问题，以及菜单打开弹窗后丢失返回焦点的问题。独立复核覆盖上述生命周期、曲线手势结束、历史可用性和表单语义。

完整前端 199 项测试、生产构建与差异检查通过，生产依赖审计无漏洞。构建仍提示单入口 JavaScript 包超过 500kB；当前约 611kB，gzip 约 203kB，后续可按照片工具与资产库拆分加载。

验收专用工作区、会话、版本和资产已清理，原工作区参数与原有资产保持一致，主题偏好恢复。真实效果与相机实机验收继续待办。

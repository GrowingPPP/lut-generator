# 照片放大查看

生成页照片工具栏提供“放大查看”。现有嵌入预览承担调色时的总体判断；放大查看提供接近整个视口的独立照片区域，便于比较细节。照片缩放、平移与模式切换不修改调色参数；窗口内的调色面板编辑当前草稿，行为见[放大查看中的参数调整](photo-detail-editing.md)。

## 查看行为

- 点击入口后打开有焦点约束的对话框，默认适应窗口，沿用当前滑动或并排模式。提供滑动对比、并排、仅原图和仅效果。版本 A/B 比较中沿用固定的 A/B 参数与名称。
- 提供适应窗口、1:1 像素、缩小和放大。缩放范围为 25%～400%；适应窗口可低于 25%，使整张照片完整显示。1:1 表示一个图像像素对应一个 CSS 像素，窗口中显示当前分辨率及缩放比例。
- 滚轮围绕鼠标位置缩放；拖动照片平移，两个比较图同步保持同一缩放比例与图像位置。对比分界使用单独滑杆，避免与平移手势冲突。键盘支持缩放、适应窗口、1:1 和平移。
- 有原文件时，“1:1 像素”或原分辨率入口按需取得规范化原尺寸照片；默认先显示已有预览。原尺寸沿用方向、ICC、Adobe RGB 与 V-Log 输入解释，不直接使用未经色彩处理的来源 JPEG。对话框内复用已加载图像，关闭后释放。
- 原文件缺失时可检查兼容缓存预览，明确显示其尺寸；无真实样张时可查看合成示意图，明确其用途。样张文件与缓存均缺失时入口不可用并提示绑定照片。
- 输入未确认或不匹配时只展示原图及当前原因，不能把未应用效果表述为 LUT 结果。版本比较未选择 A/B，或两版输入基准不同，入口不可用并说明原因。
- 使用与嵌入预览相同的 LUT 引擎、33³ LUT、外部 LUT 资源和显示编码转换。图像从规范化像素直接渲染，不能从缩略 JPEG 或屏幕截图生成效果。
- 加载或渲染失败时就地显示原因，保留可用原图。过期响应不能写入其他照片；关闭取消网络读取、释放 GL 资源和临时对象 URL。

## 布局与操作

大屏使用中性的照片背景，控制区与照片区分开，尽量让照片占据可用空间。手机控制区可换行，照片区域独立接收手势，不产生横向页面溢出。关闭按钮和 Escape 始终可用；焦点返回打开入口，背景滚动位置保持。

## 验收

使用 `_1026453.JPG` 验证 2048×2048 预览与 4000×4000 原尺寸载入。检查打开后照片可用高度显著大于嵌入预览、1:1 和缩放范围、指针定位缩放、同步平移与切换查看模式。核对缩放前后和关闭后参数无变化，当前效果与同分辨率的普通预览一致。

覆盖待确认输入、缓存无原文件、缺少照片与合成示意图、版本 A/B、三种主题和手机尺寸。后端原尺寸路径遵守既有上传/像素边界，默认规范化仍保持 2048px 上限。验证前端测试、相关照片接口测试及生产构建。

### 2026-10-10 验收结果

- 实际样张 `_1026453.JPG`：预览 2048×2048，按需加载的原照片 4000×4000；原尺寸 1:1 可以正常渲染。
- 在 1767×939 视口中，放大窗口照片区为 1598×719；并排两图同步平移 100×40px、滚轮缩放至 122.1%，图像变换保持一致。滑动对比的分界滑杆独立变化，手动 400% 缩放可用。
- 原尺寸适应窗口为 17.975%，继续缩小保持适应状态，不反向放大。Escape 关闭恢复入口焦点及背景滚动；查看及其快捷键没有改变草稿曝光 0.15 EV 或三条调整历史。
- 将曝光调整为 0.15 EV 后，对普通预览及放大窗口的 2048×2048 RGBA 像素计算 SHA-256：两处原图均为 `91fe3be533b4e48b8e5bdf86aa8d82a39e31aa20801bed7775926f6af6580e75`，两处效果均为 `b7fd568a19d7d66eec4cb29ac1fe58e448c6c25356fd747591cd89224df37d88`。效果确实改变，且同分辨率渲染结果一致。
- 390×844 视口默认滑动对比，照片区为 390×562.5，无横向页面溢出。浅色、灰色和深色主题正常使用，中性照片背景保持一致。
- 重新载入后的兼容缓存明确显示“缓存预览 · 无原文件”和 2048×2048，1:1 标注为预览像素；未确认输入仅显示原图并禁用效果模式。缺少照片时入口禁用并提示重新绑定；无样张时明确显示合成示意图。
- 版本 A/B 沿用固定快照及名称；缺少任一比较版本时入口禁用。查看器回退原图时，按钮名称与高亮依据实际显示内容。
- 前端 178 项测试、相关照片接口与色彩处理 64 项测试及生产构建通过。几何、元数据身份和取消请求回归包含在测试中；独立代码审查发现的缩小方向及回退标签问题均已修复。
- 浏览器验收使用独立工作区；验收结束后恢复原工作区与主题偏好，移除验收创建的工作区、会话及本机缓存。

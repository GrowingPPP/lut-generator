# 面向新手的参数使用说明

## 目标

让用户在调色时理解每项参数，并能从明确的创作意图开始尝试。说明在参数附近按需展开，普通工作区与放大查看共用内容，不改变当前参数、历史或草稿。面板保持紧凑，照片始终可见。

## 交互与内容

- 手动调整和放大调色栏提供折叠的“新手创作指南”，建议依次确认输入、校正照片、调整影调、创造色彩、对比与收敛效果。每次只改一项，用对比和撤销判断结果；提供可尝试的小幅数值，无自动套用。
- 每个参数组展开后先显示一句用途。普通参数名称旁增加“？”按钮，点击或键盘激活后在本项下方展开说明；同一控件面板每次只展开一项。保护状态不妨碍阅读。
- 每项说明包括“它改变什么”“减小／增大后怎样”“可以试试”“使用提醒”，按类型调整标题；非数值参数不强行解释为左右滑动。
- RGB 分通道以偏移、中间调、增益三项解释，各自说明 R/G/B 与互补色的关系。自由曲线说明横纵轴、主曲线与通道曲线、控制点操作，并给出单独通道的方向提示。
- 输入基准、V-Log 显示映射、外部 LUT 与叠加强度也有说明，明确输入匹配、转换与创意叠加的区别。
- 说明使用可阅读文字，不依赖悬停、颜色或浏览器 title。展开状态和面板之间使用唯一的可访问关系；触控、窄屏、三种主题可用，无嵌套弹窗。

## 内容依据

帮助数据精确覆盖引擎现有字段与分组，范围和方向以实际前后端算法为准。冷暖为相对偏移；绿／洋红正值更绿；Gamma 大于 1 提亮中间层次；RGB 偏移与增益并非只作用于暗部或亮部。局部色彩按颜色处理整图，参数保护不锁定空间区域。风格强度保留输入、曝光与白平衡，包含系统曲线的创意贡献，外部 LUT 强度独立。高光、白部与阴影不能恢复已经丢失的信息。

分离色调平衡在 0 的高光权重应为 0；原实现与邻近值不连续，需同时修正前后端这一端点，并验证默认值及其他权重不变。

## 验收

- 帮助字段精确覆盖所有引擎参数、七个参数组与独立的自由曲线模块；内容非空，无修改参数操作。
- 新手指南、参数说明、输入、外部 LUT 与四通道曲线能在实际页面阅读。
- 在放大窗口打开帮助后，缩放与平移位置不变，可继续调整同一参数，关闭帮助不改变历史。
- 键盘和触控可展开／收起；主页面与放大窗口同时存在时说明 ID 唯一，保护项可读；窄屏无横向溢出，三种主题文字清楚。
- 分离色调端点回归、前端测试、参数契约测试和构建通过，并进行独立语义与交互复核。

### 2026-10-10 验收结果

- 帮助数据精确覆盖 34 个参数字段，每项具备用途、方向、尝试与提醒；七个实际参数组及独立曲线模块均有说明，指南包含五条步骤。契约测试检查新参数不会遗漏帮助。
- 普通面板用 Enter 展开指南、用空格展开绿／洋红说明，展示与实现一致的“增加绿色”方向。曝光受保护时滑杆禁用，帮助按钮仍可使用。各面板同时展开曝光说明时 ID 唯一。
- 用 `_1026453.JPG` 确认 STD 输入后，在 4000×4000 原分辨率、100% 与平移状态下打开帮助。参数与历史条数保持一致，照片区域高度保持 761px。两图变换均为 `translate(-1311px, -1594.5px) scale(1)`；继续将曝光调到 0.05 EV 时两图位置仍保持一致。
- 自由曲线说明用键盘展开，主曲线与 R/G/B 的方向提示全部显示；后续 Tab 进入主曲线控制点，Escape 正常关闭查看器。
- 输入说明明确普通 JPEG 不能当作 V-Log 滤镜；阅读后输入保持 STD。临时导入一个 sRGB 恒等 LUT，验证从放大栏最后的强度滑杆按 Tab 可到外部 LUT 说明，Enter 展开后再 Tab 返回窗口首个按钮。焦点约束已纳入原生 summary、照片区域与曲线可聚焦元素。
- 390×844 下页面宽度为 390px，无横向溢出；展开帮助后照片区约 390×301、调色区约 390×287，帮助独立滚动。浅色、灰色、深色主题检查通过。
- 分离色调零点错误先被前后端回归复现，各两项失败；修正后零点与非纯白近零样本正常，默认 0.5 的三段染色结果保持一致。
- 前端 184 项测试、后端影调与参数契约 46 项测试及生产构建通过。帮助内容、参数保护、焦点导航与改动范围完成独立只读复核。
- 验收只使用临时工作区；结束后删除该工作区、其本机草稿与临时 LUT，恢复原工作区及主题偏好，没有调用 AI 作业。

## 独立复核与修复

实现与复核由不同任务执行。复核及验收发现的以下问题均已修复：

- 参考匹配父级上下文对象每次渲染变化，导致请求结束时候选被清空：稳定上下文并保留来源核对。
- 外部 LUT 的延迟加载可能与曲线手势混成一次事务：将加载状态传给父级统一冻结编辑，面板响应校验不因自己的加载状态拒绝候选；卸载使迟到响应失效。
- 恢复作业在等待外部资源后仍需核对草稿：在异步预载后再次检查来源和当前参数，确认本机持久保存后才标记完成。
- 参考匹配的风险检查使用过小图像：最终风险检查提高到长边 512，同时保留快速候选搜索。
- 结构化曲线及外部参数需要完整历史比较：改为递归结构比较，旧 30 字段草稿迁移只补四个中性默认值，不掩盖已有无效值。
- 图片大小边界兼容及纯引擎接口依赖：恢复图片上限契约，通过公共引擎接口处理解析错误并在 API 返回明确状态。

复核确认外部异步加载问题闭环；未留下本轮直接关联的 P1/P2 问题。

## 当前使用边界与待办

- **运行中的 AI 作业**仍由单进程内存管理；刷新恢复依赖当前服务继续运行，不支持服务重启后的运行续接或多实例作业调度。已经正式保存的成功结果可从数据库恢复。阻止迟到提交的回执同样有进程及保留期限边界。
- **参考匹配**比较影调和色彩分布，在现有参数里寻找更接近的效果，不能复制构图、光源、材质和空间处理。
- **外部 LUT**仅支持纯 3D、2–65 点、输出值 0–1 的 SDR 文件。显示风格须与当前编码兼容；V-Log→Rec.709 输入转换强度固定为 100%。不支持 1D、混合 LUT 或 HDR。完整效果统一烘入 33³ LUT，高密度文件的细节可能有所减少。
- **自由曲线**每通道 2–16 点，输出非降且限制在 0–1，以保持影调次序。AI 保留手动曲线及外部选择。
- **照片导出**为原分辨率 JPEG 或 8 位 PNG，输入上限 32MB/64MP。刷新后需重新绑定原文件才可导出原分辨率照片；本机预览缓存不代替原文件。
- **真实照片的艺术效果、真实模型效果矩阵及相机导入/实拍验收**继续待办，本轮没有将软件回归结果等同于上述验收。

## 四通道独立展示调整

按用户反馈，主曲线与 R/G/B 从切换同一个图形改为四个同时显示的独立编辑块。每块有颜色标识、控制点图形、输入/输出百分比、删除点和通道复位；选择与文字草稿独立，完整曲线组仍由父级统一管理。

- 前端 141 项测试通过，生产构建成功，`git diff --check` 通过。
- 浏览器分别设置主曲线/R/G/B 输出为 4%/6%/3%/2%；撤销蓝通道后另外三条保持原值，重做恢复蓝通道。
- 自由曲线保护同时禁用四块。拖动红通道时其他数值输入和操作按钮冻结；Escape 恢复原值，完成拖动后一次撤销恢复原值。
- 主曲线双击增加一个中间点，另外三条控制点数量保持不变；删除所选中间点有效。
- 1440px 视口显示四列、1280px 两列、390px 单列，均没有横向溢出。图形最大宽度限制为 320px，避免宽卡片造成过长滚动。
- 独立只读复核通过：最新完整状态不会被单通道旧快照覆盖，第二指针不能提前结束活动手势，保护、异步冻结、取消与撤销接线保持有效。

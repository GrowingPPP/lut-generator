# 图像与调色能力扩展设计

日期：2026-10-10。用户批准按统一色彩管理、刷新恢复 AI 作业、参考图风格匹配、外部 `.cube` 导入与试套、自由曲线编辑的顺序实施，并增加调整后照片导出。集成与验收遵循此顺序，独立底层模块可以并行实现。真实模型效果评价与相机实拍验收继续延期。

## 统一色彩管理

- 普通照片在后端以 Pillow ImageCms 读取有效 ICC 并转换到 sRGB，统一 EXIF 方向后返回长边最多 2048 的无损 PNG。前端预览、诊断、本机预览缓存使用这些规范化像素；AI 对原文件采用同一解码路径。
- 无 ICC 的 RGB 明确标为假定 sRGB；无法证明编码的 Adobe RGB、无配置 CMYK、损坏 ICC 不静默当作 sRGB。明确告知用户转换来源。
- V-Log 输入保留原编码值，跳过 ICC 显示转换。LUT 输出仍是 Rec.709；网页最终显示将 Rec.709 传递函数转换为 sRGB，不重复显示映射，不改变 LUT 数值。
- 规范化版本、输入基准、来源摘要和原始尺寸进入样张元数据。旧预览或输入改变时需要重新规范化；照片原文件只在页面内存和单次请求中使用，不保存到服务器。

## 刷新恢复 AI 作业

- 提交前把作业 UUID、冻结参数、上下文、工作区和样张来源写入账号隔离的 IndexedDB 回执，不保存 File 或照片像素。
- 刷新并恢复同工作区后，在编辑可用前查询实际作业状态。网络中断保持冻结；只有确认终态或明确阻止迟到提交后才解冻。
- 成功候选应用时重新核对完整起始参数、上下文、工作区和来源。原文件没有重新绑定时可查看、应用已正式保存的匹配结果，重试和续跑仍需原文件。
- 应用事务采用作业 UUID，保存已应用标识，避免刷新、撤销后再次恢复同一作业。确认本机草稿保存成功后才完成回执。
- 服务端正式报告保留 job_id 与请求指纹。服务在保存后重启仍可查询正式结果；正在运行的作业不承诺重启续跑。
- 查询不到的提交使用原子拒绝回执阻止该 UUID 迟到登记；不能用一次 404 推断尚未到达的请求已取消。

## 参考图风格匹配

- 参考图独立上传，不成为 AI 主样张，也不自动改变当前输入。参考图采用普通 sRGB 显示照片，原图按工作区已确认输入处理。
- 比较影调分位数、色彩倾向与饱和度分布，在现有可表达的参数中搜索候选。支持色彩、影调开关及匹配强度；不承诺复制构图、光源、材质或空间效果。
- 参数锁、输入只读、数值范围与新增图像风险检查生效。曲线和外部 LUT 原样透传，匹配在完整当前效果上评估。
- 显示原效果、参考图与候选、统计距离改善及受阻原因。候选预览不改草稿，确认应用才形成一条风格事务，可撤销并提取有效贡献。
- 上传与响应均核对冻结来源，过时响应不能应用。服务端不保存参考照片，确定性匹配不调用真实模型。

## 外部 LUT

- 严格解析 3D `.cube`，支持 2–65 点、R 最快数据顺序、有限数值和有效输入域；格式混合、行数不符或不支持的指令明确拒绝。
- 用户必须确认输入输出编码。显示风格支持 sRGB→sRGB 或 Rec.709→Rec.709，作用于系统完整效果后，强度 0–1。
- V-Log→Rec.709 技术 LUT 使用 input 模式替换系统技术转换，强度固定 1，系统 tone_map 不再参与；随后进行现有相对调色和自由曲线，避免两次技术转换。
- 外部 LUT 是账号内不可变引用，数据独立保存，参数只记录 ID、模式与强度。纯引擎通过解析器传入数值网格，不能直接依赖数据库。
- 预览、AI 分析、诊断、照片导出、LUT 导出共享合成结果。缺失或越权引用拒绝渲染，不能静默丢弃。草稿、撤销、版本和资产均保存引用。

## 自由曲线

- 主曲线及 R/G/B 曲线，每通道 2–16 个点；横坐标严格递增，端点横坐标为 0/1，输出 0–1 且非降。采用单调三次插值，避免段内过冲和影调反转。
- 四个通道各有独立编辑块，同时展示图形、所选控制点的输入/输出百分比及删除、复位操作。主曲线使用暖白标识，R/G/B 使用对应颜色；空间足够时并排，窄屏纵向排列。各通道独立保留控制点选择，完整曲线组仍共用一套参数和撤销事务；拖动期间不接受其他通道的编辑。
- 支持增加、拖动、删除中间点，精确数值、键盘操作、单通道复位与整体保护。一轮拖动为一次撤销操作。
- 曲线在显示编码域应用并烘入 33³ LUT。所有入口透传同一曲线。曲线操作为绝对 set，配方不把嵌套控制点当 RGB 增量。
- 外部选择与曲线由专用手动入口编辑；AI 提议保留这些字段，不编造其参数。工具 schema 与可写字段契约分别验证。

## 调整后照片导出

- 导出当前选中且输入匹配的真实样张完整效果，提供 JPEG（质量可调）和 PNG。使用重新绑定的原文件保持原始分辨率；没有原文件时明确提示绑定。
- 从同一 33³ 合成 LUT 分块渲染原图，输出统一 sRGB。V-Log 的 Rec.709 输出仅在照片显示编码环节转换，不再次调色。
- 文件名称标明已调整；嵌入 sRGB ICC，去除 GPS、拍摄者及旧方向等源元数据。下载确认成功前不显示完成。
- 请求冻结当前参数和原文件摘要；响应迟到仍对应这份冻结效果，界面标明导出的效果。保留现有 32MB/64MP 输入上限并限制并行内存使用。

## 验证

- ICC 变换、错误配置、方向、无配置与 V-Log 原编码；规范化前后端像素一致；输出尺寸、ICC 和元数据。
- 回执恢复、网络与 404 竞争、重复应用、撤销后刷新、来源冲突、保存失败与服务重启后的正式结果恢复。
- 参考匹配实际改善、锁保护、非法参数和风险拒绝、强度零、场景差异、过时响应。
- cube 格式与输入域、身份/通道交换/非线性采样、越权引用、技术替换；曲线单调、identity、插值与配方语义；前后端合成与导出一致性。
- 完整后端/前端回归、生产构建、浏览器关键流程与独立审查。数据库测试只使用 chroma_test，真实模型与相机验收保持待办。

## 技术依据

- [Pillow ImageCms](https://pillow.readthedocs.io/en/stable/reference/ImageCms.html)：ICC 转换与输出配置文件。
- [PCHIP 插值定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)：保形单调三次插值的斜率规则；两端实现使用相同公式。
- [OpenColorIO 文件格式支持](https://opencolorio.readthedocs.io/en/stable/guides/using_ocio/using_ocio.html)：cube 的格式来源与支持边界。

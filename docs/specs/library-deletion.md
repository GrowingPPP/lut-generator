# 我的 LUT 删除入口

## 目标与范围

删除功能目前仅在资产详情底部，卡片上不可发现。每张卡片提供明确的「删除」文字入口，保留详情删除入口，二者共用确认与请求流程。

## 交互

- 卡片主操作为预览／载入，详情、编辑和删除为次要操作；删除使用主题危险色，不依赖悬停显示。
- 确认弹窗展示资产名称，说明会永久删除资产及全部调色修订且不能撤销。已载入工作区的效果、草稿、保存版本和导出文件保留。
- 默认聚焦取消；取消或 Escape 不发删除请求，从详情进入时可返回原详情。发送期间显示「正在删除…」，禁止重复提交或关闭，并保持焦点在弹窗。
- 请求失败时保留弹窗与具体错误，允许重试；404 视为资产已不存在，从列表移除过期项。
- 成功后立即移除卡片、更新数量，再刷新资产库。刷新失败与删除失败分别反馈。原有筛选保持生效，删除某分组最后一项后仍显示当前空组筛选，避免界面回显与筛选条件不一致。
- 删除成功通知生成工作区清除匹配的保存资产引用，下次保存创建新资产；调色参数、撤销历史和工作区版本不改。

## 验收

用临时资产验证卡片与详情入口、取消、Escape、确认成功、数量更新、筛选空态、刷新持久化、失败重试与重复点击。确认当前载入资产删除后再保存不再尝试更新已删除资产。检查三种主题与390px窄屏；独立源码审查与前端测试、生产构建通过。验收仅删除本次创建的临时资产。

## 验收记录

- 旧界面卡片无删除入口，详情底部已有删除；新界面每张卡片的预览主操作下方直接展示删除文字。
- 临时资产确认弹窗默认聚焦取消；Escape 恢复卡片删除按钮焦点，资产仍可读取；从详情进入后取消返回详情。
- 模拟删除503时显示具体错误、保留弹窗且能重试；重试等待期间快速点击两次只发送一次请求，取消／确认按钮禁用，Escape和Tab保持在弹窗内。
- 确认成功后资产读取404，卡片立即移除。模拟后续汇总刷新503时明确显示「已删除，列表刷新失败」；手动刷新恢复正确总数。删除分组最后一项后保持「原分组（暂无资产）」和原筛选值一致。
- 临时资产已载入工作区时，删除前保存弹窗有更新选项，删除后更新选项消失；参数及撤销历史完整保留，再保存生成新的资产ID。
- 资产在服务端先删除后，再确认前端过期卡片的删除，404路径正常清理列表；刷新页面后仍保持正确资产数量和删除入口。
- 深色／中性灰危险按钮使用深色前景，浅色使用白色前景。桌面确认框宽460px；390px页面确认框宽374px，未产生横向溢出。
- 前端188项测试、后端2项既有删除关键测试与生产构建通过。后端测试使用隔离测试库；独立源码审核通过。
- 验收仅删除两个临时资产，原有资产全部保留；临时工作区、会话与本机记录已清理，并恢复原工作区和主题。
